## Reading this map

- **Full/backend**: the stated P3 backend clause has substantive executed regression evidence. This is not whole-rule/rendered/live acceptance.
- **Mixed**: a meaningful part is exercised, but another clause, edge or consumer remains unproved. Later-phase parts remain strict.
- **Missing**: no substantive evidence located for the named clause; existence of a method, fixture constant or test name is not proof.
- **Decision**: captured behavior is intentionally retired/corrected under the contract/decisions; imported state and remaining consumers are not thereby waived.
- References `J:name`, `PG:name`, etc. mean the exact symbol in the file alias below, **not** a fabricated Rust module path. A range of IDs in a row applies the stated classification to each ID, with exceptions called out.
