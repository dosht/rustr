# SOL critique of the frozen Opus P6 proposal

2026-10-26. Bounded cross-critique authorized by lead. This critique was written before design exchange with Opus. Originals remain unchanged. Read `../opus/proposal.md` (snapshot 6E0A), the accepted P5 D20 and the exact sources named below. No implementation, checks/builds/browser/provider calls or new agents. Verdict: **changes needed before an implementation contract**; strong agreement on the architecture, but finite-routing and evidence claims need correction. This is not implementation authorization or lead approval.

## Agreements worth keeping

Opus has the more concrete reusable serving adapter: content-addressed HTML, a route manifest, a useful `cms-http`, and an executable two-locale Taskr host. These are real module responsibilities, not empty crates. Both proposals retain the immutable 4,527 baseline, pruned-but-reachable routes, Rust SEO policy, real P3/caption/capture islands, two product images plus the existing processor, and P7/P9/live dependencies. Pure build-time billing projection is a viable smaller alternative to SOL's proposed runtime enhancement; the required projector does not exist yet, as R confirmed. P5 **D20 already decides `/_app/*` versus public `/assets/*`**; remove it from outstanding decisions, do not reopen it.

## Proposed convergence and remaining decisions

Converge on the neutral manifest/core, a concrete reusable static-serving adapter, real Taskr consumer and Svelte/wasm public tools. Accept build-only public pricing with an enforced digest/release contract; no new public pricing API is necessary on that basis. Keep exact source oracle and page/routing semantics as the first gate. Treat D20 as closed. Keep E1 measured.

Lead/mu still decide per-URL SEO-D01..06; unknown reverse/certificate/language restrictions; date normalization/loser-slug disposition; reachable public translation gaps; permission/resource/error corrections; raw mail-body safety; legal/capability/price truth and one-versus-two embeds. P7 docs/keys and P9 DNS/TLS/trusted-IP/catalog release/live captures/search/mail/provider rights remain explicit gates, not deleted scope. No implementation or canonical gate is approved by this critique.
