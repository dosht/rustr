## S0 and evidence precision

S0 executes only after the independent test owner receives an explicit checkpoint authorization. It runs a disposable copy, never writes to the original Transgate tree, and uses controlled outbound fixtures with no production cookies, credentials, mail or provider calls. Pin source hashes, Node/dependencies, timezone, as-of clock and observed traversal order. Preserve raw source records separately from resolved URLs and rendered results. Record rendered, hydrated and configuration-only evidence as different classes.

Next's permanent/temporary redirect objects support an expectation of 308/307. No P6 HTTP oracle has run. Exact status, Location encoding and the legacy redirect-config path remain unobserved. The lead amended the overstatement in `opus/response.md` after Fable's review; that correction changes evidence wording, not the routing proposal.

## Remaining approval and execution gates

- Mu approves final legal/privacy wording and the disposition of unsupported capability, accuracy, retention and location claims, including LNG-D10. Existing false promises do not become true by copying them. Keep source text for the oracle and produce explicit proposed corrections; do not publish an invented guarantee or treat model flags as deletion evidence.

- P7 owns docs/key routes; P9 owns edge deployment, production auth/provider/mail/storage settings and paired pricing releases. Local fixture passes cannot close live-provider, search, payment or capture-device acceptance.
- E1 has not run and no framework is selected. No S0, P6 browser, content-import or packaged verification has run.
