# P8-ANDROID: the Compose shell (p1Z)

`transgate/apps/android`, package `dev.transgate.android`, over the generated `dev.transgate.core` bindings (`transgate_ffi.kt`). Decisions D5-D8, D10-D12, D14 of `docs/plans/p8-shells/decisions.md`.

## Shape

| Layer | Files | Rule |
|---|---|---|
| Composition root | `MainActivity.kt`, `TransgateViewModel.kt`, `ShellHost.kt` | Builds the one `TransgatePresenter`, forwards every intent on a single lane, publishes the view core answers with. The `ViewListener` only schedules a `current()` read on that same lane, so an effect's view can never overtake a later intent's answer. A `Leave` with an app path (locale switch) disposes and recreates the presenter at that path, as a browser reload does. |
| `NativePorts` | `ports/AndroidNativePorts.kt` and helpers | Fulfils the ports; decides nothing. A failure is a failure value, core chooses what the person sees. |
| Screens | `ui/*Screen*.kt`, `TranscriptLines.kt`, `AnalysisBlocks.kt` | Render the view model, forward intents. Copy only through `Copy`/`tk()`/`Msg.text()` (strict `translate()`); colors only through `MaterialTheme` or `Tone.color()`. |
| Tokens | `ui/DesignTokens.kt` (generated by `scripts/gen-tokens.py`, p24) | Paper palettes, light/dark by system theme. |

## Ports (D7, D8, D10, D11)

- **Storage (D8):** `KeystoreVault`, AES-GCM under a non-exportable Android Keystore key; a value the key cannot open is dropped (no session).
- **Auth (D7):** core's Google redirect arrives as `leave(url)` and opens in a Custom Tab. GoTrue returns to `dev.transgate.app://auth?code=`; `MainActivity` hands the path and query to core as `RouteChanged`, which recognizes the PKCE callback and exchanges it with the verifier core stored. The scheme is `SITE_URL` (`-Ptransgate.siteUrl`), which the host must allow-list as a redirect.
- **Files:** `PickedFiles` keeps the content URI by handle (`OpenMultipleDocuments`, accept list from `UploadQueueVm.pickerAccept`), measures with `MediaMetadataRetriever`, PUTs once with the content type and reports progress; only HTTP 200 is success (UPL-013/014).
- **Player:** `PlayerHost`, one `MediaPlayer`; reports `PlayerState` to core, serves the pause/resume/seek ports. D11: a YouTube transcript mounts no player; `seek` opens `watch?v=ID&t=Ns` in the YouTube app or browser.
- **Output:** clipboard, save (MediaStore Downloads, API 29+), preview (FileProvider + `ACTION_VIEW`), share (chooser). Documents handed to other apps are staged under `cache/outgoing`.
- **Assets (D10):** the fonts and invoice logo are read from `transgate/export/{fonts,assets}` as Gradle asset dirs (one copy, no duplicate); `provenance.json` is excluded, the OFL texts ship.
- **D6:** balance is shown. There is no purchase button, no store link and no external purchase link. The 402 alert shows its text and OK only. Invoices and API keys are two drawer rows that open `webUrl/billing` and `webUrl/dashboard/api-keys` in a Custom Tab (`-Ptransgate.webUrl`).
- **TLS (D9):** bundled roots, in `transgate-client`; the `.so` is the only thing the shell links.

## Build

```sh
scripts/build-transgate-android.sh        # cargo-ndk into app/src/main/jniLibs (TRANSGATE_ANDROID_BUILD_STD=1 on Arch, TRANSGATE_ANDROID_ABIS to limit)
cd transgate/apps/android
export JAVA_HOME=$(mise where java@temurin-21.0.12+8.0.LTS) ANDROID_HOME=$HOME/Android/Sdk
mise exec gradle@8.14.6 -- gradle assembleDebug assembleDebugAndroidTest \
  -Ptransgate.apiUrl=http://192.168.240.1:8080/api -Ptransgate.authUrl=http://192.168.240.1:54321/auth/v1 \
  -Ptransgate.authKey=<anon key> -Ptransgate.webUrl=http://192.168.240.1:8080
```

`192.168.240.1` is Waydroid's gateway to the host. `jniLibs/`, `build/`, `.gradle/` and `local.properties` are git-ignored.

## Acceptance test (D14)

`app/src/androidTest/.../SignedInFlowTest.kt`, UiAutomator, driven by Compose test tags exposed as resource ids:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -e email <e> -e password <p> dev.transgate.android.test/androidx.test.runner.AndroidJUnitRunner
```

Account precondition: its newest job is COMPLETED with lines. Tests: sign in shows the frame and balance; **edit a line, save, leave the transcript and reopen it (read back from the host), then restore the original**; cancel keeps the stored text; sign out returns to sign-in.

## Not proven

Nothing here has run on a device or emulator. Proven: Kotlin compiles, `assembleDebug` and `assembleDebugAndroidTest` link, the keycheck (every fixed label exists in all 16 catalogs) passes, bindings `--check` matched at the time of writing. Unproven: every runtime behavior (Keystore on Waydroid, Custom Tab return, signed PUT, MediaPlayer, layout of any screen, the UiAutomator run itself).
