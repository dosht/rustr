# P8-IMPL-2: `transgate-ffi`, `translate()` and bindings (p22)

## What exists

- **`transgate/i18n` (`transgate-i18n`, D3).** `translate(locale, &Msg)` over the 16 web catalogs embedded with `include_str!`. Same policy as `web/src/lib/i18n`: no fallback language, literal namespace and key, `{{name}}` interpolation without escaping, a numeric `count` tries `<key>_<CLDR category>` then the plain key, nested message arguments are translated first, and an unknown locale, key or argument is an error. Tests: CLDR categories, strict errors, **every translation uses the placeholders of its English source in all 16 locales**, **every `Msg` the fixtures emit (more than 200, real arguments) translates in all 16 locales**, every `reachable-keys.json` key exists in all 16.
- **`transgate/ffi` (`transgate-ffi`, D2).** UniFFI 0.32. `TransgatePresenter` is a `Send + Sync` handle to an `AppDriver` that lives on its own thread (current-thread runtime plus `LocalSet`). Shells call `dispatch`, `current`, `session_changed_elsewhere` and `dispose`, off their main thread. Views reach the shell's `ViewListener` on a second thread, in order, so a listener may call back into the presenter (tested). The foreign side implements `NativePorts` (secure session storage, navigation, external browser, calendar offsets, file measure and PUT with progress, player, clipboard, save, preview, share, bundled assets); every slow call runs on a blocking thread, never on the driver thread. `translate()` and `ui_locales()` are exported.
- **Core view models as remote types.** `src/remote.rs`: 145 remote Record and Enum declarations of the `AppVm` and `AppIntent` graph (156 types with the converted ones). `src/custom.rs`: `Msg` (to `MsgWire`, `HashMap` and a recursive `ArgWire`), `Decimal`, `Language`, the analysis `Rating`, `JobId`, `LineId`, `Micros`, `AccountId`, `KeyId`, `usize`, `[i64; 3]` hour presets, the `(usize, u8)` fade and the two `OptionVm<T>` instances. **Core did not change**; the orphan-rule risk named in the feasibility note did not materialise (every alias custom type compiled first time).
- **Bindings.** `scripts/gen-bindings.sh` now generates and checks `taskr-ffi` and `transgate-ffi`. Outputs: `transgate/apps/android/app/src/main/java/dev/transgate/core/transgate_ffi.kt` and `transgate/apps/ios/Generated/{TransgateCore.swift,TransgateCoreFFI.h,TransgateCoreFFI.modulemap}`. The existing gate (`gate-rustr.sh`, `gates.yml`) already runs `gen-bindings.sh --check`.

## Drift is a compile error, not a convention

`remote.rs` is **hand-maintained**. Each declaration repeats a core type, and UniFFI's generated code moves every field and matches every variant, so a core field, variant or type that changes, or a newly reachable type with no declaration, fails the build of `transgate-ffi`. This happened during the work: p1X added `DataManagementVm.save_error` and the build named it (`missing field save_error`); one line followed. No generator is committed because the compiler is the check. The declarations were first drafted from rustdoc JSON; that script is not part of the repo.

The one tool-dependent decision: ambiguous Rust names got one foreign name each (`AnalysisDecision`, `ConsentDecision`, `ChatRating`, `AnalysisRating`, `DataManagementConfirmVm`, `BillingConfirmVm`, `ApiKeysIntent`, `SettingsIntent`), because the Kotlin and Swift namespace is flat and Android's `Intent` must stay free.

## Verification and what is not proven

Executed: `cargo test -p transgate-i18n` (7), `cargo test -p transgate-ffi` (custom-type round trip; the presenter handle end to end through fake `NativePorts` and `ViewListener`, a loopback host, the real `AppDriver`, `HttpApi` and `GoTrue`: a stored session restores, signs in and lists jobs, a listener re-enters the presenter, dispose is idempotent and later calls return `Disposed`; strict `translate`), clippy `-D warnings` on both crates, and `scripts/gen-bindings.sh` then `--check`.

Not proven: any Kotlin or Swift **compile or run** of the generated files (no compiler here; Y's Swift image and Waydroid are the gates). `SpeakerLabel::None` and `Media::None` generate `case none`; Swift may warn where `SpeakerLabel?` is matched. Generation did not break, so core is unchanged; rename only if the Swift compile fails. No Android `.so` has been built (no NDK target installed), so the D9 bundled-roots path and `aws-lc-sys` cross compilation are unexercised.

`NativePorts.asset` names the bundled files: `NotoSans.ttf`, `NotoSans-Italic.ttf`, `NotoSansArabic.ttf`, `NotoSansSymbols2-Regular.ttf` (symbols), `NotoSansSymbols.ttf` (arrows), `invoice-logo.jpg`, and each `FallbackFont::filename()`, matching the web base mapping.
