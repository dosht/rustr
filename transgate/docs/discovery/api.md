# Public API and HTTP routes

The public transcription API accepts API keys or a browser session through one service, with v1-beta compatibility wrappers.
API keys are opaque `sk_` values with bcrypt hashes, not Supabase JWTs; a scoped Supabase JWT is generated internally after key verification.
Completed jobs can POST results to customer callback URLs. Sources are read-only under `/home/mu/Business/Transgate`; no production queries were made by this worker.

## Inventory

Route census: **40 Next API route paths**, comprising **33 Pages API handler files** and **7 App Router route.ts files**. Excludes colocated tests and `v1-beta/transcriptions/auth.ts` (helper, not route.ts). App routes export 11 explicit method handlers; Pages handlers have mixed method dispatch, so 40 is a path count, not a method count. The parity table records all 40 paths.

Trim has 6; convert-audio 5; reduce-audio 5; remove-noise 5; video-to-audio 6; compress-video 6; convert-video 6.
